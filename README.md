# GNSS Filter v10.12.4

Android-застосунок: перевіряє GPS і віддає навігатору лише перевірену
позицію, коли сигнал глушать або підміняють. Android 10+, Java, без
сторонніх бібліотек, окрім Google Play Billing.

**Приватний репозиторій.** Як улаштовані алгоритми, пороги й рішення —
у [`docs/INTERNALS.md`](docs/INTERNALS.md). Той файл назовні не виносити.

## Збірка

Збирає GitHub Actions (`.github/workflows/build.yml`) на кожен push і вручну
(Actions → build-apk → Run workflow). Gradle 8.11.1, AGP 8.9.1, JDK 17,
`compileSdk`/`targetSdk` 36.

| Артефакт | Що це | Для чого |
|---|---|---|
| `gnss-filter-apk` | debug-APK, без обфускації | польові випробування, ставиться напряму на телефон |
| `gnss-filter-aab-play` | release-AAB, з R8 | завантаження в Google Play |
| `gnss-filter-apk-release-r8` | та сама release-збірка як APK | перевірити обфусковану збірку на телефоні до завантаження в Play |
| `r8-mapping` | `mapping.txt` | розшифровка стеків падінь release-збірки |

Три останні з'являються лише коли задані секрети підпису: `KEYSTORE_B64`,
`KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` (Settings → Secrets and
variables → Actions). Без них збирається тільки debug-APK з тимчасовим ключем.

## R8 (обфускація) — що це змінює в роботі

Нічого. Вихідні файли лишаються звичайними й читабельними — працюєте з ними
як завжди. Перейменування класів, методів і полів відбувається **всередині
release-збірки**, автоматично, щоразу; окремо нічого робити не треба.
debug-APK збирається без обфускації.

Два правила:
- перед завантаженням нової версії в Play поставити на телефон
  `gnss-filter-apk-release-r8` і пройти звичайний сценарій (Старт, мок,
  OBD, ручна точка, логи) — саме ця збірка піде користувачам;
- зберігати `r8-mapping` кожної версії, що пішла в Play. У AAB словник
  вкладається сам, тож у Play Console стеки вже розшифровані; файл потрібен
  для стеків, які надішлють вам напряму.

Правила — `app/proguard-rules.pro`. Якщо в коді з'явиться рефлексія
(`Class.forName`, `getDeclaredMethod`, Gson тощо), відповідні класи треба
додати туди через `-keep`, інакше release-збірка впаде там, де debug працює.

## Реліз у Google Play

1. Підняти `versionCode` і `versionName` в `app/build.gradle` та `VER` у
   `FilterService.java` — Play не прийме той самий `versionCode` двічі.
2. Push → дочекатись зеленого CI → завантажити `gnss-filter-aab-play`.
3. Тексти лістингу, записка рецензенту — `PLAY_LISTING.md`; політика
   конфіденційності — `PRIVACY_POLICY.md` (публікується окремо, у публічному
   репозиторії).

## Після кожного оновлення APK

Android скидає вибір mock-застосунку при перевстановленні: Developer options
→ Select mock location app → GNSS Filter. Якщо пропустити — червоний
заголовок «Мок заборонено» і сповіщення «НЕ ПРАЦЮЄ» з вібрацією.

## Мова інтерфейсу

Українська (для мов `uk`, `ru`) та англійська (решта); на Android 13+ мову
можна обрати окремо для застосунку в системних налаштуваннях. Переклади —
у коді поруч з оригіналом: `T.s("Старт", "Start")`, клас `T.java`.
Подробиці — в `docs/INTERNALS.md`.
